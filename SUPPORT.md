# Support

## Questions and usage help
- Read README.md and INSTALLATION.md first.
- Search existing issues and discussions before opening a new request.
- For reproducible defects, open a GitHub issue with the skill name, library version, client name/version, steps to reproduce, expected result, and actual result.
- Redact private data, credentials, personal information, and customer content.

## What maintainers can assess
- Skill wording, activation descriptions, workflow quality, validation issues, installation problems, and repository documentation.
- Cross-client behavior only when the reporter supplies enough safe reproduction details and an exact client/version.

## Limitations
This is a community library, not a hosted service or a guarantee of agent behavior. There is no guaranteed response time, uptime, or support SLA. For security vulnerabilities, follow SECURITY.md instead of filing a public issue.
