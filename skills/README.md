# Skills Directory

Each directory contains one portable Agent Skill in SKILL.md format.

- Keep folder name and frontmatter `name` identical.
- Keep descriptions concise, specific, and clear about when the skill activates.
- Keep SKILL.md focused and under 500 lines where practical.
- Put detailed long-form material in a skill-local `references/` directory.
- Link all three shared root files using the documented relative path.
- Update CATALOG.json and the routing matrix whenever the inventory changes.
- Run the repository validator and unit tests before submitting changes.

See [../README.md](../README.md), [../INSTALLATION.md](../INSTALLATION.md), and [../CONTRIBUTING.md](../CONTRIBUTING.md).
