# Security Policy

## Scope
This policy covers the skills, shared rule documents, installer, validator, tests, and repository workflows in this public project.

## Reporting a vulnerability
Please do not publish exploitable details in a public issue.

Use GitHub's private vulnerability reporting feature:
https://github.com/shreeramcomputers/Universal-AI-Agent-Skills-Library/security/advisories/new

Include:
- Affected file, version, or workflow.
- Preconditions and impact.
- Minimal reproduction or proof that avoids exposing real user data.
- Suggested remediation, if known.

Do not include live credentials, private keys, personal data, or customer records in the report. If GitHub private reporting is unavailable, contact the repository maintainers through a private GitHub channel before public disclosure.

## Response and disclosure
This is a community-maintained repository with no guaranteed response time or service-level agreement. Maintainers will assess severity, request safe reproduction details, coordinate a fix, and publish an advisory when appropriate.

## Safe use
- Skills do not grant permissions or make an AI client secure by themselves.
- Review skill content and scripts before use.
- Run tools with least privilege and in a test environment first.
- Never install unknown skills into a privileged production agent without review.
