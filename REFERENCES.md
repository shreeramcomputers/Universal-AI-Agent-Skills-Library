# Research and Reference Projects

The library follows the open Agent Skills folder format and studies public design patterns from established skill collections. These projects are independent; this repository is not affiliated with or endorsed by them.

## Format and specification
- [Agent Skills specification](https://agentskills.io/specification)
- [agentskills/agentskills](https://github.com/agentskills/agentskills)

## Public collections reviewed
- [anthropics/skills](https://github.com/anthropics/skills) — examples of modular skill folders and references.
- [obra/superpowers](https://github.com/obra/superpowers) — composable workflows for planning, implementation, testing, debugging, and review.
- [mattpocock/skills](https://github.com/mattpocock/skills) — small composable skill design and installation patterns.
- [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) — end-to-end engineering lifecycle and quality gates.
- [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) — task-specific engineering, UI, and documentation skills.
- [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill) — evidence-led multi-phase defensive auditing.
- [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) — specialist skills with clear task boundaries.

## Use of references
These repositories and public documentation were reviewed for structure, workflow design, testing, progressive disclosure, and quality practices. No third-party SKILL.md files are copied into this library. Links are provided for readers to inspect original projects and their current licenses. Always check each source's current license and attribution requirements before reusing any of its material.
